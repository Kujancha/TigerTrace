# Raw ATRW inputs

Download the Re-ID training/test image and annotation archives from https://lila.science/datasets/atrw.

Extract the CSV and JSON **directly beside the corresponding images**:

- `train/reid_list_train.csv`
- `train/reid_keypoints_train.json`
- `test/reid_list_test.csv`
- `test/reid_keypoints_test.json`

Image basenames remain unchanged. Raw data is ignored by Git; it is not distributed here. See the root README for full setup, commands, protocol scope and dataset terms.
